# AMI Portal

AMI Portal — це інформаційна платформа для студентів, викладачів та абітурієнтів факультету прикладної математики та інформатики Львівського національного університету імені Івана Франка.

Проєкт розроблений у межах бакалаврської кваліфікаційної роботи та спрямований на створення єдиного цифрового середовища для отримання навчальної інформації, взаємодії між учасниками освітнього процесу та підтримки студентської спільноти.

## Основні можливості

### Форум

* створення та редагування дописів;
* коментування публікацій;
* категоризація дописів;
* система вподобань;
* підтримка анонімних повідомлень;
* пошук та сортування дописів.

### Карта курсів

* перегляд освітніх програм факультету;
* інформація про навчальні дисципліни;
* структура навчання за семестрами;
* відображення кредитів та типів контролю.

### Розклад занять

* перегляд розкладу за академічними групами;
* підтримка чисельника та знаменника;
* відображення аудиторій, викладачів та типів занять;
* автоматичне оновлення даних із PDF-розкладів.

### Медіатека

* централізоване зберігання навчальних матеріалів;
* категоризація ресурсів;
* підтримка різних типів контенту;
* перегляд та завантаження матеріалів.

### FAQ

* база відповідей на поширені запитання;
* швидкий доступ до важливої інформації для студентів та абітурієнтів.

### ШІ-помічник

* пошук інформації по платформі;
* відповіді на типові запитання;
* інтеграція з GenAI API;
* підтримка нечіткого пошуку.

### Система сповіщень

* повідомлення про зміни на платформі;
* відстеження нових подій;
* позначення прочитаних сповіщень.

## Архітектура системи

Проєкт реалізовано за клієнт-серверною архітектурою.

### Frontend

* React 19
* React Router
* Context API
* CSS Modules
* Vite

### Backend

* Java 21
* Spring Boot 3
* Spring Security
* Spring Data JPA
* QueryDSL
* Flyway
* JWT Authentication

### PDF Processing Service

Окремий сервіс для аналізу PDF-файлів розкладу занять:

* Python
* FastAPI
* PDF Parsing

### Database

* PostgreSQL
* Supabase

---

## Безпека

Система підтримує:

* JWT-автентифікацію;
* рольову модель доступу;
* захист REST API через Spring Security;
* контроль доступу до адміністративного функціоналу.
